# Fotos dos profissionais da comissão técnica

Imagens estáticas em WebP, de 256 × 256 px, com fundo transparente, usadas na Central Free Fire.
A foto representa o profissional, independentemente da camisa da organização ou da temporada.

Para adicionar as fotos otimizadas, abra esta pasta no GitHub e use **Add file > Upload files**.
Coloque aqui os 17 arquivos `.webp` da pasta `assets/coaches` do ZIP otimizado.
Não suba o ZIP inteiro como um arquivo do site.

O caminho é `/assets/coaches/nickname.webp` e o mapeamento é
`js/coach-photo-map.js`. Imagens ausentes usam `/silhueta.webp`.

Apelidos ambíguos (FRANK x FRANK7, WF9 x WF, Bryan x BryanKing)
devem ser confirmados antes de associar a foto.
