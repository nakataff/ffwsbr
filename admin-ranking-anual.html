Editor do ranking anual

Mude pontos e pesos, confira como a classificação fica e exporte a configuração. Nenhum resultado oficial de torneio será alterado.

1. Temporada

Os dois anos usam hoje os mesmos critérios, mas podem ser ajustados separadamente.

Este editor só prepara arquivos locais. Para publicar no site é preciso enviar os arquivos ao GitHub; não há acesso direto nem senha ou token armazenado aqui.

2. Peso dos campeonatos

Exemplo: 1º lugar com 200 pontos base e peso 3 = 600 pontos CFF.

3. Pontos por colocação

Edite as dez faixas. As posições dentro da mesma faixa recebem pontos iguais.

4. Prévia do ranking

#EquipePontosDiferença*

* Diferença de pontos em relação ao ranking atualmente publicado. Global Finals só entra quando estiver encerrado. O desempate continua o mesmo.

5. Publicar alterações

Um JSON por ano alterado. A geração e os testes dos rankings públicos acontecem automaticamente no GitHub.

Carregando dados…

  1. Edite os valores e clique em Baixar configuração (ou baixe os dois anos).
  2. Abra ranking-data no GitHub e envie o arquivo brasil-2026-source.json ou brasil-2025-source.json, substituindo o antigo.
  3. Após confirmar a alteração no GitHub, o workflow regenera os rankings compactos. Confira o resultado da automação antes de considerar publicado.

Pontuação editável sem banco de dados, serviços externos ou novas requisições para quem visita o ranking.
