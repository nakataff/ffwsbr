# CFF Looker Bridge

Extensão local do Chrome para conectar o `admin-dados.html` do Central Free Fire ao Looker Studio da Garena.

## Instalação

1. Baixe esta pasta `cff-looker-bridge` para o computador.
2. Abra `chrome://extensions`.
3. Ative **Modo do desenvolvedor**.
4. Clique em **Carregar sem compactação**.
5. Selecione a pasta `cff-looker-bridge`.
6. Abra o relatório da Garena em uma aba do Chrome e mantenha essa aba logada.
7. Abra `admin-dados.html` e use **Buscar T1 + P1 da Garena**.

A extensão não lê senha e não armazena cookies. Ela executa a consulta dentro da aba do Looker já autenticada.

## Observação

O importador atual foi preparado para a **Fase 2 / Segunda Fase** da WB 2026 S2 usando os componentes T1 e P1 identificados no relatório da Garena.
