CONFIGURAÇÃO DO PAINEL ADMINISTRATIVO - CENTRAL FREE FIRE

IMPORTANTE
A senha NÃO fica no código do site. Cadastre-a somente no Firebase Authentication.
Não coloque a senha em HTML, JavaScript, JSON, GitHub ou arquivo de configuração público.

1. ATIVAR LOGIN POR SENHA
- Abra o Firebase Console do projeto central-free-fire.
- Entre em Authentication > Sign-in method.
- Ative Email/Password.
- Em Authentication > Users, crie o usuário administrador:
  E-mail: admin@centralfreefire.com.br
  Senha: use a senha definida pelo proprietário do site.

2. REGRAS DO REALTIME DATABASE
- Abra Realtime Database > Rules.
- Mescle/publice o conteúdo de firebase-database-rules-admin.example.json.
- Não deixe uma regra geral como ".write": true na raiz.
- O bloco adminHiddenNews é necessário para que uma notícia local excluída pelo painel não volte a aparecer pelo arquivo de fallback.
- Teste as regras no simulador antes de publicar.

3. ACESSO AO PAINEL
https://centralfreefire.com.br/admin.html

4. NOTÍCIAS JÁ INCLUÍDAS
- O arquivo noticias-painel.json contém as notícias do TSV enviado.
- Elas já aparecem no site como fonte local/fallback.
- Dentro do painel, use "Importar notícias do arquivo" uma vez para copiá-las ao Firebase e poder editar normalmente.
- A planilha continua disponível pelo botão "Sincronizar planilha".
- Quando o mesmo slug existe em mais de uma fonte, a versão publicada pelo painel tem prioridade.

5. EDITOR
- Cada Enter cria um novo parágrafo. Não é mais necessário digitar [P].
- Os [P] antigos continuam sendo aceitos.
- Selecione um texto e clique em "Título de tópico" para gerar [H: TEXTO].
- Selecione um texto e clique em "Subtítulo" para gerar [H3: TEXTO].
- Se o conteúdo começar com [H: ...], esse texto vira o título grande da matéria.
- A primeira marcação [IMG: URL] vira automaticamente a imagem principal e não se repete no corpo.
- Também é possível colar o link diretamente no campo "Imagem principal da notícia".
- Outras marcações [IMG: URL] inseridas depois continuam aparecendo dentro do texto.

6. CONTADORES DO FIREBASE
- Visualização de notícia: uma por sessão do navegador em cada notícia.
- Curtida: fica marcada no navegador e pode ser removida clicando novamente.
- Páginas mais vistas: uma por sessão em cada página ou seção/hash visitado.
- São métricas simples; o painel do Google Analytics é a referência oficial de audiência.

7. GOOGLE ANALYTICS
Leia GOOGLE_ANALYTICS_SETUP.txt para configurar o Client ID OAuth e o ID numérico da propriedade GA4.
Nenhum Client Secret ou senha do Google deve ser colocado no site.

8. LIMITAÇÃO DE SEO
Notícias publicadas pelo painel aparecem imediatamente na home e em noticia.html?id=SLUG.
O painel estático não cria automaticamente uma pasta /noticias/SLUG/ nem atualiza sitemap.xml/news-sitemap.xml.
Isso exigiria uma função de servidor ou fluxo de build seguro.
